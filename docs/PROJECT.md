# StudyLog 프로젝트

## 1. 서비스 한 줄 소개

StudyLog는 공부 시간을 기록하는 일을 귀엽고 지속 가능한 경험으로 바꾸는, 캐릭터 중심의 모바일 스터디 앱이다.

## 2. 제품 목표

- 사용자가 부담 없이 공부를 시작하고 꾸준히 기록하도록 돕는다.
- 공부 중인 상태와 성취를 도트 캐릭터의 행동과 성장으로 보여준다.
- 친구와 같은 공간에서 공부하는 듯한 연결감을 제공한다.
- 일별·주별 기록과 통계를 쉽고 즐겁게 돌아보게 한다.

## 3. 핵심 사용자 경험

1. 사용자가 공부 목표나 과목을 정하고 타이머를 시작한다.
2. 집중 중에는 캐릭터가 공부하거나 펜을 굴리는 등 현재 상태에 맞게 반응한다.
3. 자리를 비우거나 앱에서 이탈하면 이를 감지해 실제 집중 기록과 구분한다.
4. 공부가 끝나면 시간과 과목이 기록되고, 통계와 보상에 반영된다.
5. 누적 기록으로 캐릭터가 성장하고 꾸미기 아이템을 얻는다.
6. 친구와 공부방에 참여해 함께 공부하고 서로의 진행 상황을 확인한다.

## 4. 핵심 기능

### 공부 기록

- 일반 타이머와 포모도로 타이머
- 과목·목표별 공부 시간 기록
- 공부 완료 기록 및 공유용 기록 카드
- 일별·주별·누적 통계

### 집중 상태

- 공부 중 캐릭터 애니메이션
- 졸거나 쉬는 상태를 보여주는 `ZZZ` 표현
- 앱 이탈 또는 자리 비움 감지
- 실제 집중 시간과 이탈 시간을 구분한 기록

### 친구와 함께 공부

- 공부방 생성·입장
- 같은 공간에서 공부하는 캐릭터 표현
- 친구의 공부 상태와 누적 기록 확인
- 경쟁보다 함께 꾸준히 하는 경험을 우선하는 랭킹과 알림

### 성장과 꾸미기

- 공부 시간과 목표 달성에 따른 포인트·성장
- 도트 캐릭터 및 꾸미기 아이템
- 사용자의 공부 이력이 캐릭터의 변화로 이어지는 보상 구조

## 5. 제품 원칙

- 캐릭터는 장식이 아니라 공부 상태와 성취를 전달하는 핵심 인터페이스다.
- 기록은 정확해야 하며 사용자가 언제든 이해하고 수정할 수 있어야 한다.
- 기능을 늘리기 전에 공부 시작부터 기록 완료까지의 기본 흐름을 안정적으로 만든다.
- 경쟁을 강요하지 않고, 작은 성취와 꾸준함을 긍정적으로 강화한다.
- 모바일 화면과 짧은 조작 흐름을 가장 먼저 고려한다.

## 6. 현재 기술 구성

- 프런트엔드: React, TypeScript, Vite
- 스타일: Tailwind CSS
- 상태 관리: Zustand
- 데이터·인증: Supabase
- 서버: Express
- 배포: Vercel

## 7. 문서 사용 방법

Claude Code와 Codex는 작업을 시작하기 전에 이 문서와 함께 다음 문서를 읽는다.

- `DESIGN.md`: 화면과 상호작용의 공통 기준
- `ROADMAP.md`: 기능 우선순위와 개발 순서
- `RULES.md`: 코드 수정, 검증, 보고 규칙

요청 내용이 문서와 충돌하면 임의로 결정하지 말고 사용자에게 확인한다.
